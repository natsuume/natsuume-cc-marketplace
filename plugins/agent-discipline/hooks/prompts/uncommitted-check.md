各ファイルを以下のいずれかに分類する:
- **(a) 今回のタスクに関連** — 作業継続として stage / commit
- **(b) 以前のタスクの残骸** — 別ブランチ / 別コミット / 削除
- **(c) 中間状態** — `git stash` で退避
- **(d) 不明** — ユーザに分類を依頼

すべてが明らかに (a) かつ小規模な場合でも、この確認を省略しない。この規定は auto mode の自走方針より優先する (誤分類で誰かの未公開作業を push する事故を防ぐため)。agent-discipline の commit→PR→merge フローは、`AskUserQuestion` の回答で分類が確定してから進めること。
