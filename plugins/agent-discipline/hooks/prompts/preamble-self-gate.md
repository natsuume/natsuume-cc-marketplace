(自己ゲート) このセッションのモデルを hook からは判定できなかった。以下の見出し「# agent-discipline: 常時適用ルール (Sonnet)」から始まる常時適用ルールのブロック (本メッセージ内に後続の見出し「# agent-discipline: 分業規律 (Fable セッション)」がある場合はその直前まで、無い場合はメッセージ末尾まで) は、SONNET 向けの書式 (適用範囲の明示、良い例・悪い例の併記など) で書かれた agent-discipline の常時適用ルールである。この規律自体はモデルによらず適用されるため、あなた (メインセッション) がどのモデルであっても従うこと。後続の分業規律ブロックが存在する場合、その適用可否は当該ブロック冒頭の前置き (自己ゲート) の指示に従う。

自分が Fable である場合は、SONNET 向けの詳細な書式にとらわれず、各ルールの見出しと最初の 1〜2 文 (意図と適用範囲の要点) を優先して読めばよい。良い例 / 悪い例や細部の列挙は必要な時にのみ参照すること。自分のモデルは自身の system prompt (例: Environment セクション) のモデル情報で確認できる。
