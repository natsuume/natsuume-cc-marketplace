これは natsuume 名義の技術文書（テックブログ・技術書）の地の文に適用される執筆ルールの要点です。執筆と無関係な作業では無視してよい内容です。

## 通底原則（迷ったらここから導出する）

1. 断定度は情報源に比例させる。公式仕様は断定し、自分で検証した事実は「筆者が実際に試した限りでは」と帰属を明示し、未検証の推測は婉曲表現に落とす
2. 読者と並走する。同じ実践者として情報を共有する距離感を保ち、読者が抱きそうな疑問は先回りして代弁する
3. 冷静・抑制。感嘆・煽り・過度な形容を使わず、淡々と事実と根拠を積む
4. 鮮度と限界を明示する。執筆時点・バージョン・条件を明記し、情報が古くなる可能性と自分の記述の限界を隠さない

## 文末表現の要点

- です・ます調のみ（だ・である調を混ぜない。体言止めは見出し・表内のみ可）
- 「！」は使わない。「？」もほぼ使わない（例外は自問自答の導入のみ）
- 断定度の使い分け: 仕様・事実は断定、推奨は「〜がよいでしょう」、推測は「〜と考えられます」、筆者の運用・好みは「〜と思います」
- 同一の文末表現を近接させない（「でしょう」を含む文を 2 文連続で置かない等）

## 表記の要点

- ひらがなに開く: こと / できる / ため / ない / よい / すべて / さまざま / わかる / いただく
- カタカナ語の長音符号は省略しない（サーバー / ユーザー / リポジトリー / ライブラリー 等）
- 数字は算用数字（漢数字は使わない）。英数字は半角
- 「※」は使わない。注記・補足は「なお、」「ただし、」で地の文に統合する

## 詳細ルールへの案内

ここにあるのは要点のみです。執筆作業（章立て・たたき台作成・推敲・レビュー）では、この plugin 配下の `rules/writing-rules.md`（共通コア全文 + 書籍/ブログの媒体プロファイル）を読み込んで従ってください。執筆支援 skill（outline / draft / review）は今後のバージョンで追加予定であり、現時点では存在しません（存在しないコマンドを提案・実行しないでください）。
