# session-handoff: context 使用率が閾値を超えました

現在の会話の context 使用率が閾値を超えました。このまま作業を続けると、途中で context が尽きて
それまでの作業内容が失われるおそれがあります。

今取り組んでいる作業を、切りの良い単位まで進めてください。その後、`__HANDOFF_PATH__` に
次の 6 項目構成で handoff ドキュメントを書いてください。

1. 背景・目的
2. 完了済み作業
3. 進行中の作業と現在の状態
4. 残作業・次の一手
5. 決定事項・制約
6. 参照ファイルパス・関連 issue・PR

未コミットの変更がある場合は、その旨と変更の所在 (ファイルパス等) を必ず handoff に明記してください。

書き終えたら、保存したパスと要点をユーザに報告し、`/clear` の実行を案内してください。
`/clear` 後の新しいセッションでは、この handoff の内容が自動的に注入されます。
